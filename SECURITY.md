# Security Policy

## Supported versions

Release metadata identifies supported versions. Fixes outside a supported
release line are applied to `main`.

## Reporting a vulnerability

Please report suspected vulnerabilities privately. Do not open a public issue,
pull request, or discussion for a security report, and do not disclose the
issue publicly until a fix is available.

Send reports to security@uldren.ai or use GitHub's private vulnerability
reporting on the repository's Security tab ("Report a vulnerability"). Include:

- A description of the issue and its impact.
- The affected component, branch, or commit.
- Steps to reproduce or a proof of concept.
- Any suggested remediation.

Do not include real credentials, secrets, or personal data in a report. If a
secret was exposed, describe the exposure without pasting the secret value.

## Handling and disclosure

Reports are triaged privately and addressed through coordinated disclosure. We
will acknowledge a report, work toward a fix, and credit reporters who wish to
be credited once a remediation is available. Timelines depend on severity and
complexity.

## Scope

This policy covers the source in this repository. Vulnerabilities in Uldren
Core, Uldren Mobile, hosted services, or third-party dependencies should be
reported through the corresponding project's security channel.
